NEW CHAPTER TEMPLATE

To start a new chapter of this campaign:
  1. Copy this _template folder and paste it right here, next to the other chapters.
  2. Rename the copy: lowercase letters, numbers, and dashes, such as remnant or season-2.
  3. Open campaign.md in the copy and set the Name.

That's it.  A few seconds later the new chapter shows up on the build page with its
session files.  Folders whose names start with _ (like this one) are always skipped.

A chapter inherits everything from the campaign.md one folder up: crest, motto,
skins, triggers, worlds, shared briefs, images, sounds, and media.  Set something in
the chapter's own campaign.md (or add a file to its folders) to override it.
